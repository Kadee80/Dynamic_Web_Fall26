## 3. Build a recipe card in HTML

Make a folder called `Week01` in your homework repo, and inside it build a plain
**HTML** page for a recipe you actually like and would actually make.

It needs:

- a photo of the finished dish (a placeholder is fine if you don't have one)
- the name of the recipe
- a short description — a sentence or two
- a list of ingredients
- a numbered list of instructions

CSS is **optional**. Don't spend your evening on the styling; we style it
together in week 3.

> **Why HTML and not React?** Because next class we convert your file, line by
> line, into a React component — and it lands much harder when it's your own
> markup and your own recipe than when it's mine. Pick something you don't mind
> looking at for three weeks.

## 4. Finish your setup if it isn't done

If `node -v`, `npm -v` and `git --version` don't all print a version number,
come to office hours before the next class. Do not wait. Do not try to catch up
during week 2 — you'll be behind on two things instead of one.

## Submitting

```bash
git add .
git commit -m "week 1 homework"
git push
```

Then open your repo on github.com and confirm you can see your files there. If
you can see them in the browser, I can see them too.

**Documentation is 5% of your grade at IDM.** A clean repo, a real README, and
commented code is the easiest 5% in the program.
